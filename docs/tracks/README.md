## Purpose

Implementation tracks turn accepted decisions and runbooks into execution
checklists. Use them for active work that is not yet fully automated.

## Template

Each implementation track should include:

- Scope and non-goals.
- Known inputs and decisions.
- Ordered phases.
- Validation gates.
- Automation follow-up.
- Rollback notes.
- Evidence log.
