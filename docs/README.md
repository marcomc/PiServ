## Purpose

This directory stores runbooks, decisions, implementation tracks, and
supporting notes for the PiServ server setup.

## Structure

| Path | Purpose |
| --- | --- |
| `runbooks/` | Step-by-step operational procedures |
| `decisions/` | Durable architecture and operations decisions |
| `tracks/` | Active implementation checklists and validation gates |

## Writing Rules

- Keep procedures task-oriented.
- Include exact commands when documenting live server work.
- Capture observed results, not expected results only.
- Link related decisions from runbooks when a command exists because of a
  durable choice.
